==================================================
PACK SCI-FI LOW POLY – README (FR)
==================================================

Merci d’avoir téléchargé ce pack d’assets 3D sci-fi low poly.

-------------------------------------------
CONTENU DU PACK
-------------------------------------------
- Fichiers FBX (un par asset)
- Fichiers OBJ + MTL
- Fichier source : .blend
- Images de présentation (préviews)
- Documentation + licence d’utilisation

-------------------------------------------
UTILISATION
-------------------------------------------
Tous les modèles sont prêts pour une utilisation dans :
- Unity
- Unreal Engine
- Godot
- Blender
- Maya / 3dsMax / Cinema4D
- Tout autre logiciel compatible FBX ou OBJ

Les modèles sont low poly, non texturés (couleurs simples), organisés,
optimisés et exportés proprement.

-------------------------------------------
ORGANISATION DES DOSSIERS
-------------------------------------------
01_BLEND       : fichier source Blender
02_EXPORT      :
   - FBX       : modèles triangulés
   - OBJ       : modèles + fichiers .mtl
03_IMAGES      : rendus de présentation
04_DOCS        : README + Licence

-------------------------------------------
CONSEILS D’IMPORTATION
-------------------------------------------
- FBX recommandé pour Unity / Unreal Engine
- OBJ recommandé pour les outils plus anciens
- Le fichier .blend peut être utilisé directement dans Blender

Tous les modèles ont une origine correctement placée et les transformations appliquées.
