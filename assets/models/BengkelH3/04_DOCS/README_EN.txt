==================================================
SCI-FI LOW POLY PACK – README (EN)
==================================================

Thank you for downloading this low poly sci-fi 3D asset pack.

-------------------------------------------
PACK CONTENT
-------------------------------------------
- FBX files (one per asset)
- OBJ files + MTL
- Source file: LowPoly_SciFiPack_HS_002.blend
- Preview images
- Documentation + license

-------------------------------------------
USAGE
-------------------------------------------
All models are ready for use in:
- Unity
- Unreal Engine
- Godot
- Blender
- Maya / 3dsMax / Cinema4D
- Any software compatible with FBX or OBJ

Models are low poly, non-textured (flat colors), optimized and clean.

-------------------------------------------
FOLDER STRUCTURE
-------------------------------------------
01_BLEND       : Blender source file
02_EXPORT      :
   - FBX       : triangulated models
   - OBJ       : models + .mtl files
03_IMAGES      : preview renders
04_DOCS        : README + License

-------------------------------------------
IMPORT TIPS
-------------------------------------------
- FBX is recommended for Unity / Unreal Engine
- OBJ is recommended for older tools
- The .blend file can be used directly in Blender

All models have correctly placed origins and applied transforms.
